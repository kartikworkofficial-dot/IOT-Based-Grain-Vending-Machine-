# Project scope and future work

## Scope represented in the materials

The project is framed as an automated grain/ration vending machine for possible use in India's Public Distribution System. It focuses on RFID-based user identification, user input through a keypad, a microcontroller-controlled dispensing mechanism and weight feedback from a load cell/HX711. The block diagram also includes an ESP8266 IoT module, ultrasonic sensor, alarm and LCD. GSM transaction communication is described in the report.

## Future scope explicitly listed in the source

1. Use consumer-interaction data to analyze consumption patterns, preferences and demand trends.
2. Develop a mobile application that synchronizes with the machine so consumers can check product availability, place orders remotely and receive collection notifications.
3. Integrate the machine with government databases and systems for social welfare programmes, subsidy distribution and citizen identification.

These items are future scope, not completed features. The materials do not establish that mobile ordering, live inventory, government integration, remote control, digital payments or cloud analytics were implemented.
