# Contributing / maintaining this project archive

This repository is an evidence-based archive of an academic project. Keep changes faithful to the actual prototype and original records.

- Do not describe a feature as implemented unless the team can provide supporting evidence.
- Mark reconstructed code and proposed improvements explicitly; never label them original.
- Keep future scope separate from implemented functionality.
- Record and resolve source-document discrepancies with evidence rather than silently editing values.
- Do not commit passwords, API keys, phone numbers, private identifiers, signatures or confidential academic records.
- Add only photographs, diagrams and code that the contributors have permission to publish.
- Add a license only after all relevant rights holders agree to its terms.
